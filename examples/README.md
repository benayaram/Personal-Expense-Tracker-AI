# Fictional sample backup

Open sample-backup.json, copy all its JSON text, and paste it in Moneywise → Settings → Restore backup → Check backup. Review and confirm replacement. Export any existing records first: restore replaces the ledger, not merges it.

All records are fictional, dated October 2026. The sample has 9 transactions (including an excluded transfer), 4 budgets, 2 goals and 2 recurring bills. Expected income ₹60,000, expenses ₹32,500, tracked balance ₹27,500 and estimated safe-to-spend ₹10,000. Dining is ₹1,800 above its sample budget. No API key or real financial data is included.

If viewing a different month, select October 2026 under Activity. Set your own starting data before using the app for actual finances.
