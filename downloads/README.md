# Download Moneywise for Android

[Download Moneywise-Android.zip](https://github.com/benayaram/Personal-Expense-Tracker-AI/raw/refs/heads/main/downloads/Moneywise-Android.zip)

1. Download the ZIP (about 75 MB). Sign into GitHub with access to this repository if it is private.
2. Extract it using your phone's Files app.
3. Open **Moneywise-1.0.0.apk** to install the evaluation build.
4. Open Moneywise → Settings → Gemini API settings to enter your own key on the phone. No hosted backend is required.

The archive contains the original verified, debug-signed universal APK, installation notes and its SHA256 checksum. The app requires Android 7 or later on a supported ARM/ARM64/x86_64 device. No API key or personal transaction data is included.

This is an evaluation build. Physical-device notification testing, a real Gemini request and production signing remain release gates. See [validation evidence](../docs/VALIDATION.md) and [release instructions](../docs/RELEASE.md).
